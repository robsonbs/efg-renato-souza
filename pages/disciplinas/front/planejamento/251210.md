Conteúdo Ministrado Na Aula *	
Boas práticas HTML (semântica, IDs/classes); CSS (box model, media queries); Acesso a código via GitHub raw files.
Objetivo	
Avaliar organização e boas práticas em HTML/CSS; Fornecer feedback sobre semântica e responsividade; Desenvolver competências de refatoração de código.
Metodologia	
Introdução (20 min): Aula expositiva dialogada sobre semântica, com exemplo de código ruim vs. bom.
Desenvolvimento (100 min): Clonagem de repos em trios; Análise de HTML/CSS (ex: "Estrutura semântica?"). Sugestões via fork e PRs. Interação: Rodadas de discussão para priorizar melhorias. Mediação: Professor demonstra merges.
Conclusão (20 min): Teste local das edições; reflexão sobre impacto no Pages.
Recursos Didaticos	
Computadores para clonagem Git;
Projetor para demonstração de PRs;
Editor VS Code com extensão GitHub Pull Requests.
Bibliografia	
MOZILLA DEVELOPER NETWORK (MDN). HTML semantics. Disponível em: https://developer.mozilla.org/pt-BR/docs/Glossary/Semantics. Acesso em: 25 set. 2024.
WORLD WIDE WEB CONSORTIUM (W3C). CSS Validator. Disponível em: https://jigsaw.w3.org/css-validator/. Acesso em: 25 set. 2024.
Avaliacao	
Qualitativa: Qualidade das sugestões em PRs (contínua). Quantitativa: Rubrica (50% organização, 50% responsividade). Feedback: Aprovação de PRs com comentários.
