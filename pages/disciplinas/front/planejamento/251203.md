Conteúdo Ministrado Na Aula *	
Configuração de repositório GitHub e deploy no Pages; Critérios básicos de avaliação: funcionalidade, código e visual; Uso de issues e README para documentação inicial.
Objetivo	
Compreender o processo de hospedagem de projetos no GitHub Pages; Realizar autoavaliação inicial do projeto final para identificar forças e fraquezas; Desenvolver competências de autocrítica e gerenciamento de repositórios digitais.
Metodologia	
Introdução (20 min): Apresentação teórica sobre GitHub Pages como ferramenta colaborativa, com demonstração ao vivo de um deploy de "Catch the Fruit". Discussão em plenária sobre importância da autoavaliação (alinhado a competências de reflexão pedagógica).
Desenvolvimento (80 min): Atividade individual: Alunos criam repositório, fazem commit do projeto e ativam Pages (guiados por tutorial projetado). Autoavaliação via formulário (Google Forms) com rubrica simples (pontos 1-5 em 5 critérios). Interação em duplas para compartilhar links e discutir achados iniciais. Mediação: Professor circula, oferecendo suporte em tempo real.
Recursos Didaticos	
Projetor multimídia para demonstração;
Computadores com acesso à internet e VS Code;
Tutorial em PDF (GitHub Pages básico);
Formulário Google Forms para autoavaliação.
Bibliografia	
GITHUB. GitHub Pages. Disponível em: https://pages.github.com/. Acesso em: 25 set. 2025.
MOZILLA DEVELOPER NETWORK (MDN). Deploying to GitHub Pages. Disponível em: https://developer.mozilla.org/en-US/docs/Learn/Common_questions/Using_github_pages. Acesso em: 25 set. 2025.
Avaliacao	
Qualitativa: Observação da participação e qualidade das anotações em issues (processual, contínua). Quantitativa: Autoavaliação pontuada (rubrica: 70% funcionalidade, 30% documentação).
